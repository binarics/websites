    • What's Hot in Design

    Design systems are evolving from static component libraries to living, breathing frameworks that adapt to user context. The best work this month shows a clear shift: fewer micro-interactions for their own sake, more attention to accessibility, and a renewed focus on performance as a design constraint rather than an afterthought.

  • Finpath — AI Finance Dashboard (General)

    • A masterclass in data-dense UI. Uses layered transparency, strategic whitespace, and progressive disclosure to present complex financial metrics without overwhelming the user. Color palette: deep purples with amber accents. The loading states alone are worth studying.

  • Ledgerix CRM — Finance SaaS (General)

    • 1,083 appreciations. Combines dark mode with high contrast ratios, floating panel architecture, and a navigation system that scales from mobile to 4K displays. The component library is modular enough to work as both a dashboard and a full CRM.

  • Stratum AI — Finance Management (General)

    • 2,147 appreciations, 47,321 views. Features a radical approach to financial data visualization: interactive 3D treemaps that collapse into 2D summaries. Uses WebGL for rendering performance while maintaining full accessibility compliance.

  • Runo — AI Fintech Platform (General)

    • 857 appreciations. A case study in AI-assisted design: the team used AI to generate 50 design variants, then refined the best through human intuition. The result: a UI that feels both familiar and surprisingly effective.

    The best design work now starts with a performance budget, not a color palette. Teams are designing for Core Web Vitals first, then building the visual layer on top. This reverses the traditional workflow but produces dramatically better user experiences — especially on mobile where 3G is still common.

    Design-to-code is finally reaching maturity. Tools that previously generated bloated, unusable markup are now producing clean, semantic HTML with proper accessibility attributes. The next frontier: design tools that can generate production-ready React components with TypeScript types, not just static mockups. Watch for tighter integration between design files and version control.
